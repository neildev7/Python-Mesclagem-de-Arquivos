# 📑 Mesclador Automático de PDFs

Este projeto implementa um **script em Python** para mesclar múltiplos arquivos PDF em um único documento final.  
O objetivo é facilitar o gerenciamento de documentos digitais, unificando arquivos separados em apenas um PDF consolidado.

Este projeto foi desenvolvido como parte do meu aprendizado em **Python**, aplicando conceitos de manipulação de arquivos, automação de tarefas e uso de bibliotecas externas.

---

## 📌 Sobre o Projeto

O sistema realiza automaticamente:

- 📂 **Leitura de arquivos** dentro da pasta `arquivos`  
- 🔎 **Identificação de PDFs** entre os arquivos disponíveis  
- 🗂️ **Ordenação alfabética** antes da mesclagem  
- ➕ **Mesclagem automática** de todos os PDFs  
- 📄 **Geração de um arquivo único** chamado `merged.pdf`  
- ✅ **Mensagem final** confirmando a conclusão do processo  

---

## 🚀 Tecnologias Utilizadas

- **Python**  
- **OS** – manipulação de arquivos e diretórios  
- **PyPDF2** – leitura e mesclagem de documentos PDF  

---

## 📂 Estrutura do Projeto

- `projeto1.py` – Script principal de mesclagem  
- `arquivos/` – Pasta onde os PDFs devem ser adicionados  

---

## ▶️ Como Usar

1. Clone o repositório ou copie o script `projeto1.py`.  
2. Instale a biblioteca necessária: pip install PyPDF2
3. Crie uma pasta chamada arquivos e adicione nela todos os PDFs que deseja mesclar.
4. Execute o script no terminal com: python projeto1.py
5. O arquivo final será salvo como merged.pdf dentro da pasta arquivos
